## Before Using

- Please run this tool with **Administrator privileges** (Windows administrator, not Endfield administrator), otherwise it cannot capture global hotkeys
- Please set the resolution to **1920×1080 window** in Endfield settings
- Press the `N` key to open the **Valuable Items** in Endfield and switch to the **Weapon Essence** page
- During operation, please ensure the Endfield window is **in the foreground**

## Features

- Press `[` key to identify whether the currently selected essence is a treasure or trash
- Press `Alt+Delete` to exit the program

**Treasure Essences and Trash Essences:** If this essence matches any weapon (all attributes of the essence are identical to at least 1 implemented weapon's attributes), it is a treasure; otherwise, it is trash.
